# WattWatch AI — Agentic Electricity Fraud Intelligence Platform

WattWatch AI is a full-stack, agentic intelligence platform for detecting, investigating, and explaining electricity fraud and anomalous consumption patterns. It combines Isolation Forest anomaly detection with IBM Granite (watsonx.ai) generative AI to produce transparent, explainable investigation summaries for utility field investigators.

---

```
┌─────────────────────▼───────────────────────────────────────┐
│                  Backend (FastAPI / Python)                   │
│                                                               │
│  ┌─────────────┐  ┌────────────────┐  ┌──────────────────┐  │
│  │ Data Service│  │ Agent Pipeline │  │  ML Service      │  │
│  │ (load/cache)│→ │ 6-step agents  │→ │ Isolation Forest │  │

│                          │                                    │
│                   ┌──────▼──────┐                            │
│                   │Granite Agent│→ IBM watsonx.ai             │
│                   └─────────────┘                            │
└─────────────────────────────────────────────────────────────┘
                      │
┌─────────────────────▼───────────────────────────────────────┐
│              Synthetic Dataset (250+ consumers)               │
│              backend/data/consumers.json                      │
└─────────────────────────────────────────────────────────────┘
```

### Agent Pipeline (6 steps)
1. **DataValidationAgent** — Validates completeness and integrity of consumer records
2. **ConsumptionAgent** — Analyzes 12-month history, computes baselines
3. **FraudDetectionAgent** — Runs Isolation Forest + statistical rules
4. **PeerComparisonAgent** — Compares consumer against peer group averages
5. **EvidenceAgent** — Builds structured evidence list from all signals
6. **RecommendationAgent** — Maps risk score + evidence to recommended field action

### Granite Integration
- Calls IBM watsonx.ai `ibm/granite-13b-instruct-v2` with structured evidence as prompt context
- Generates concise, professional investigation narratives in cautious language
- Falls back to rule-based summary if IBM credentials are not configured

## Setup & Running

### Prerequisites
- Python 3.11+
- Node.js 18+

### Backend

```bash
cd backend
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp ../.env.example ../.env      # Edit .env with your IBM credentials
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Visit http://localhost:5173

### Environment Variables

Copy `.env.example` to `.env` and fill in your IBM watsonx.ai credentials:

```
IBM_API_KEY=<your key>
IBM_PROJECT_ID=<your project id>
IBM_REGION=us-south
GRANITE_MODEL_ID=ibm/granite-13b-instruct-v2
```

The platform functions fully without IBM credentials — the AI Workspace will use rule-based summaries as a fallback.

## Responsible AI Disclaimer

WattWatch AI is a **decision-support tool only**. All AI-generated summaries and risk scores are indicative and must be reviewed and verified by qualified human investigators before any action is taken against a consumer. The system does not make accusations — it surfaces evidence for human review. Scores are computed from statistical patterns and may not reflect actual fraud.

IBM Granite model outputs are generated by a large language model and may contain inaccuracies. Always apply professional judgment.
